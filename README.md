# Sami Flowers — сайт на Next.js + Railway

Каталог, корзина, оформление заказа (WhatsApp + Telegram-уведомление) и
серверная админка (`/admin`) с базой данных (Railway Postgres). Фото
хранятся прямо в базе (без отдельного облачного хранилища).

## Деплой на Railway — по шагам

### 1. Новый проект из GitHub

1. [railway.app/new](https://railway.app/new) → **Deploy from GitHub repo**
   → выберите репозиторий `sami-flowers`.
2. Railway сам определит Next.js и начнёт первую сборку — она упадёт без
   переменных окружения, это нормально, продолжайте.

### 2. Добавить базу данных

В проекте: **New** → **Database** → **Add PostgreSQL**. Railway создаст базу
и подключит её к сервису — переменная `DATABASE_URL` появится автоматически.

### 3. Добавить остальные переменные окружения

В сервисе (не в базе!) → **Variables** → добавьте:

| Переменная | Значение |
|---|---|
| `ADMIN_PASSWORD` | Пароль для входа в `/admin` — придумайте свой |
| `ADMIN_SESSION_SECRET` | Длинная случайная строка (например, наберите на клавиатуре 40 случайных символов) |
| `SEED_SECRET` | Ещё одна случайная строка — нужна один раз, для заполнения каталога |
| `TELEGRAM_BOT_TOKEN` | `8870611187:AAG6OK9jIASLCgCByMGOEg747XupP1uZvM0` (бот `@sami_flowers_pvl_bot`) |
| `TELEGRAM_CHAT_ID` | `6851003327` |

Если `DATABASE_URL` не появилась в переменных сервиса сама — зайдите в базу
Postgres → Variables → скопируйте `DATABASE_URL` → вставьте вручную в
переменные сервиса.

### 4. Выдать публичный адрес

**Settings** сервиса → **Networking** → **Generate Domain**. Получите адрес
вида `sami-flowers-production.up.railway.app`.

### 5. Передеплоить

**Deployments** → на последнем деплое **⋮ → Redeploy** (подхватит переменные
окружения). Дождитесь статуса **Success**.

### 6. Заполнить каталог начальными товарами (один раз)

```bash
curl -X POST https://ваш-сайт.up.railway.app/api/admin/seed \
  -H "x-seed-secret: ЗНАЧЕНИЕ_SEED_SECRET_ИЗ_ШАГА_3"
```

Создаст 45 товаров (39 — с настоящими фото из вашей таблицы) в базе.
Выполнить можно повторно — не сломает данные, просто перезапишет те же
товары.

### 7. Готово

- Сайт: `https://ваш-сайт.up.railway.app`
- Админка: `.../admin` — войти паролем из шага 3, там можно менять
  названия, цены, описание, метки, наличие и загружать новые фото для
  любого товара, а также добавлять и удалять товары.

## Локальная разработка (не обязательно)

Нужен Node.js 18+.

```bash
npm install
cp .env.example .env.local   # заполните значениями из Railway → Variables
npm run dev
```

## Структура

- `app/(site)/` — публичный сайт (каталог, страница товара)
- `app/admin/` — вход и панель управления (защищены паролем через cookie-сессию)
- `app/api/` — серверные маршруты: товары (CRUD), загрузка фото, авторизация, заказы, разовое заполнение каталога
- `lib/db.ts` — работа с Postgres через `pg` (таблица `products` создаётся автоматически при первом обращении)
- `lib/auth.ts` — проверка пароля и подписанная cookie-сессия администратора
- `lib/telegram.ts` — дублирование заказов в Telegram (токен бота хранится только на сервере, не в браузере)
- `data/seed-products.json` + `public/seed-images/` — исходные данные для разового заполнения каталога
