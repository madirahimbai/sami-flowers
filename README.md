# Sami Flowers — сайт на Next.js + Vercel

Каталог, корзина, оформление заказа (WhatsApp + Telegram-уведомление) и
серверная админка (`/admin`) с базой данных (Vercel Postgres) и хранилищем
фото (Vercel Blob).

## Деплой на Vercel — по шагам

### 1. Загрузить код на GitHub

Репозиторий уже подготовлен и запушен Claude'ом в ваш аккаунт (см. сообщение
в чате со ссылкой на репозиторий).

### 2. Импортировать проект в Vercel

1. [vercel.com/new](https://vercel.com/new) → выберите репозиторий `sami-flowers`.
2. Framework Preset определится сам как **Next.js**.
3. Пока **не нажимайте Deploy** — сначала подключим базу и хранилище (шаг 3),
   иначе первый билд упадёт без переменных окружения. Можно также сначала
   задеплоить (упадёт на сборке — это нормально), а потом добавить всё
   и передеплоить.

### 3. Подключить базу данных и хранилище фото

В настройках проекта на Vercel: **Storage** →

- **Create Database → Postgres** → создать и подключить к проекту.
  Vercel сам добавит переменную `POSTGRES_URL` и другие `POSTGRES_*`.
- **Create Database → Blob** → создать и подключить.
  Vercel сам добавит `BLOB_READ_WRITE_TOKEN`.

### 4. Добавить остальные переменные окружения

**Settings → Environment Variables**, добавьте:

| Переменная | Значение |
|---|---|
| `ADMIN_PASSWORD` | Пароль для входа в `/admin` — придумайте свой |
| `ADMIN_SESSION_SECRET` | Длинная случайная строка (например, наберите на клавиатуре 40 случайных символов) |
| `SEED_SECRET` | Ещё одна случайная строка — нужна один раз, для заполнения каталога |
| `TELEGRAM_BOT_TOKEN` | `8870611187:AAG6OK9jIASLCgCByMGOEg747XupP1uZvM0` (бот `@sami_flowers_pvl_bot`) |
| `TELEGRAM_CHAT_ID` | `6851003327` |

Примените ко всем окружениям (Production, Preview, Development).

### 5. Задеплоить

**Deployments → Redeploy** (или просто новый git push). Дождитесь успешной сборки.

### 6. Заполнить каталог начальными товарами (один раз)

После успешного деплоя откройте терминал (или просто вставьте в адресную
строку через расширение типа "REST client", либо попросите Клода выполнить
curl) и один раз вызовите:

```bash
curl -X POST https://ваш-сайт.vercel.app/api/admin/seed \
  -H "x-seed-secret: ЗНАЧЕНИЕ_SEED_SECRET_ИЗ_ШАГА_4"
```

Это создаст 45 товаров (39 — с настоящими фото из вашей таблицы) в базе и
загрузит фото в Blob. Выполнить можно повторно — не сломает данные, просто
перезапишет те же товары.

### 7. Готово

- Сайт: `https://ваш-сайт.vercel.app`
- Админка: `https://ваш-сайт.vercel.app/admin` — войти паролем из шага 4,
  там можно менять названия, цены, описание, метки, наличие и загружать
  новые фото для любого товара, а также добавлять и удалять товары.

## Локальная разработка (не обязательно)

Нужен Node.js 18+.

```bash
npm install
cp .env.example .env.local   # заполните значениями из Vercel → Settings → Environment Variables
npm run dev
```

## Структура

- `app/(site)/` — публичный сайт (каталог, страница товара)
- `app/admin/` — вход и панель управления (защищены паролем через cookie-сессию)
- `app/api/` — серверные маршруты: товары (CRUD), загрузка фото, авторизация, заказы, разовое заполнение каталога
- `lib/db.ts` — работа с Postgres (таблица `products` создаётся автоматически при первом обращении)
- `lib/auth.ts` — проверка пароля и подписанная cookie-сессия администратора
- `lib/telegram.ts` — дублирование заказов в Telegram (токен бота хранится только на сервере, не в браузере)
- `data/seed-products.json` + `public/seed-images/` — исходные данные для разового заполнения каталога
